---
title: Хеш-таблица
---

Таблица «ключ — значение». Ключом может быть любое хешируемое (hashable) значение, на практике — неизменяемое: число, строка, кортеж из неизменяемых элементов. Список ключом быть не может. Самое сложное — понять, что будет ключом, а что значением.

> [!tip] Как выбрать паттерн
> - Сортировка по частоте или top-k → **KV-VK**
> - Посчитать частоты или сравнить количества → **техника подсчёта**
> - Иначе → ключ придумываем сами

## Техника подсчёта

- **Суть:** переводим условие на язык хеш-таблицы: выбираем ключ, затем считаем, сколько раз встречается каждый ключ, или ищем совпадения.
- **Когда:**
	- анаграммы и другие сравнения «чего сколько»
	- частоты элементов, элемент большинства
	- «видел ли раньше», поиск пары по значению
- **Сложность:** T: O(n) · S: O(k), где k — число различных ключей
- **Шаблон:**
	```python
	# Пример: Valid Anagram. Подсчёт пишем сами, без collections.Counter
	def count(items):
	    cnt = {}                              # ключ → сколько раз встретился
	    for x in items:
	        cnt[x] = cnt.get(x, 0) + 1
	    return cnt

	def is_anagram(a, b):
	    return len(a) == len(b) and count(a) == count(b)   # словари сравниваются по содержимому

	# «видел ли раньше»: seen = set(); if x in seen: ...

	# Пример: Two Sum. Ключ — значение, значение — индекс
	def two_sum(nums, target):
	    seen = {}
	    for i, x in enumerate(nums):
	        if target - x in seen:
	            return [seen[target - x], i]
	        seen[x] = i
	    return []

	# Пример: Majority Element (элемент, который встречается больше n/2 раз)
	# Вариант 1: подсчёт, S: O(n). Первое, что приходит в голову
	def majority_count(nums):
	    cnt = {}
	    for x in nums:
	        cnt[x] = cnt.get(x, 0) + 1
	        if cnt[x] > len(nums) // 2:
	            return x

	# Вариант 2: голосование Бойера — Мура, S: O(1). Исключение из техники: таблица не нужна
	def majority_vote(nums):
	    cand, balance = None, 0
	    for x in nums:
	        if balance == 0:
	            cand = x                      # прежняя пара «взаимно уничтожилась»
	        balance += 1 if x == cand else -1
	    return cand                           # если большинство не гарантировано, вторым проходом проверь nums.count(cand) > len(nums) // 2
	```
- **Задачи:**
	- [Valid Anagram](https://leetcode.com/problems/valid-anagram/) · Easy
	- [Ransom Note](https://leetcode.com/problems/ransom-note/) · Easy
	- [First Unique Character in a String](https://leetcode.com/problems/first-unique-character-in-a-string/) · Easy
	- [Two Sum](https://leetcode.com/problems/two-sum/) · Easy · нюанс: тут не подсчёт, а поиск пары: ключ — число, значение — его индекс, ищем `target - x`
	- [Majority Element](https://leetcode.com/problems/majority-element/) · Easy · нюанс: подсчёт требует O(n) памяти, а голосование Бойера — Мура (Boyer–Moore) обходится O(1): пары разных элементов взаимно уничтожаются, и элемент большинства переживает все такие пары. Для «больше n/3» — то же с двумя кандидатами ([Majority Element II](https://leetcode.com/problems/majority-element-ii/), Medium), для «больше n/k» — с k−1 кандидатами (алгоритм Мисры — Гриса, Misra–Gries)

## KV-VK

- **Суть:** считаем частоты, как в технике подсчёта, затем инвертируем таблицу: частоты становятся ключами, элементы — значениями. Значение — список: одну частоту могут иметь несколько элементов.
- **Когда:**
	- сортировка по частоте
	- поиск top-k элементов
- **Сложность:** T: O(n) · S: O(n)
- **Шаблон:**
	```python
	# Пример: Top K Frequent Elements. Всё пишем сами, без Counter и defaultdict
	def top_k_frequent(items, k):
	    cnt = {}                              # KV: элемент → частота
	    for x in items:
	        cnt[x] = cnt.get(x, 0) + 1

	    by_freq = {}                          # VK: частота → элементы
	    for item, freq in cnt.items():
	        if freq not in by_freq:
	            by_freq[freq] = []
	        by_freq[freq].append(item)

	    res = []
	    for freq in range(len(items), 0, -1): # от частых к редким, без сортировки
	        for item in by_freq.get(freq, []):
	            res.append(item)
	            if len(res) == k:
	                return res
	    return res
	```
- **Задачи:**
	- [Sort Array by Increasing Frequency](https://leetcode.com/problems/sort-array-by-increasing-frequency/) · Easy · нюанс: при равной частоте числа идут по убыванию. Здесь проще не корзины, а `sorted(nums, key=lambda x: (cnt[x], -x))`
	- [Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/) · Medium
	- [Sort Characters By Frequency](https://leetcode.com/problems/sort-characters-by-frequency/) · Medium
