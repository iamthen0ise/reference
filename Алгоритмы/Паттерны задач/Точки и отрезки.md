title: Точки и отрезки
---

Отрезки на прямой, как в школьной геометрии. В коде это обычно список пар `[start, end]`. Часто это отрезки времени: встречи, бронирования, поездки.

> [!tip] Как выбрать паттерн
> - Даны два списка отрезков → **два указателя на отрезках**
> - Нужно найти что-то в момент времени (сколько отрезков покрывают точку) → **метод точек**
> - Иначе → **метод отрезков**

> [!note] Базовые формулы
> - **Пересечение:** два отрезка пересекаются, если у них есть общая точка: `max(start1, start2) <= min(end1, end2)`. Сам отрезок пересечения — `[max(start1, start2), min(end1, end2)]`.
> - **Объединение:** пересекающиеся отрезки можно объединить. У объединённого начало — `min` из двух начал, конец — `max` из двух концов.
> - **Граничный случай:** считать ли касание (`end1 == start2`) пересечением, зависит от условия: отрезки закрытые (`<=`) или полуоткрытые (`<`).

## Метод отрезков

- **Суть:** сортируем отрезки по началу и проходим по ним, сравнивая текущий отрезок с последним в ответе. Главное — понять, что делать с текущим: слить с последним, добавить как новый или отбросить.
- **Когда:**
	- один список: объединить отрезки или найти пересечения
	- проверить, есть ли пересечения вообще
- **Сложность:** T: O(n log n) · S: O(n)
- **Шаблон:**
	```python
	intervals.sort(key=lambda x: x[0])
	res = [intervals[0][:]]                    # копия, чтобы не менять входные данные
	for start, end in intervals[1:]:
	    if start <= res[-1][1]:                    # пересекается с последним в ответе
	        res[-1][1] = max(res[-1][1], end)      # расширяем конец
	    else:
	        res.append([start, end])               # разрыв → новый отрезок
	```
- **Задачи:**
	- [Summary Ranges](https://leetcode.com/problems/summary-ranges/) · Easy · нюанс: отрезков на входе нет, это поиск серий подряд идущих чисел, как в [[Скользящее окно#Непересекающиеся окна]]
	- [Teemo Attacking](https://leetcode.com/problems/teemo-attacking/) · Easy · нюанс: отрезки `[t, t + duration)` уже отсортированы, ответ — суммарная длина их объединения
	- [Meeting Rooms](https://leetcode.com/problems/meeting-rooms/) · Easy · 🔒 premium
	- [Merge Intervals](https://leetcode.com/problems/merge-intervals/) · Medium
	- [Insert Interval](https://leetcode.com/problems/insert-interval/) · Medium · нюанс: список уже отсортирован, сортировать не нужно. Идём в три шага: копируем отрезки до нового, сливаем пересекающиеся, копируем остаток
	- [Non-overlapping Intervals](https://leetcode.com/problems/non-overlapping-intervals/) · Medium · нюанс: жадный алгоритм, отрезки сортируем по концу, а не по началу
	- [Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/) · Medium · нюанс: жадный алгоритм, отрезки сортируем по концу

## Два указателя на отрезках

- **Суть:** даны два списка отрезков, у каждого свой указатель, обходим их как в [[Два указателя#Каждому по указателю]]. Главное — правило сдвига: двигаем указатель того отрезка, который закончился раньше.
- **Когда:**
	- два списка отрезков, каждый отсортирован и без пересечений внутри
	- найти пересечения или общее свободное время
- **Сложность:** T: O(n + m), где n, m — длины списков · S: O(1), без учёта результата
- **Шаблон:**
	```python
	i = j = 0
	while i < len(a) and j < len(b):
	    lo = max(a[i][0], b[j][0])
	    hi = min(a[i][1], b[j][1])
	    if lo <= hi:                       # есть пересечение
	        res.append([lo, hi])
	    if a[i][1] < b[j][1]:              # двигаем тот, что закончился раньше
	        i += 1
	    else:
	        j += 1
	```
- **Задачи:**
	- [Interval List Intersections](https://leetcode.com/problems/interval-list-intersections/) · Medium
	- [Meeting Scheduler](https://leetcode.com/problems/meeting-scheduler/) · Medium · 🔒 premium · нюанс: списки сначала сортируем; ищем первое пересечение длиной не меньше `duration`

## Метод точек

- **Суть:** превращаем отрезки в точки-события (начало +1, конец −1), сортируем их и проходим со счётчиком. Главное — правильно упорядочить события с одинаковой координатой.
- **Когда:**
	- найти максимальное число одновременных событий
	- найти минимальное число ресурсов (комнат, касс, машин)
	- узнать состояние в конкретный момент времени
- **Сложность:** T: O(n log n) · S: O(n)
- **Шаблон:**
	```python
	events = []
	for start, end in intervals:
	    events.append((start, 1))
	    events.append((end, -1))
	events.sort()          # при равной координате (-1) раньше (+1): конец раньше начала

	cur = best = 0
	for _, delta in events:
	    cur += delta
	    best = max(best, cur)
	```
	Порядок «конец раньше начала» подходит для полуоткрытых отрезков `[start, end)`: там касание не считается пересечением. Если отрезки закрытые и касание — это пересечение, начало должно идти раньше конца:
	```python
	events = []
	for start, end in intervals:
	    events.append((start, 0))      # 0 < 1: при равной координате начало обрабатывается раньше конца
	    events.append((end, 1))
	events.sort()

	cur = best = 0
	for _, kind in events:
	    if kind == 0:
	        cur += 1
	        best = max(best, cur)
	    else:
	        cur -= 1
	```
- **Задачи:**
	- [Maximum Population Year](https://leetcode.com/problems/maximum-population-year/) · Easy · нюанс: отрезок `[birth, death)` полуоткрытый; запоминаем год, на котором счётчик максимален
	- [Meeting Rooms II](https://leetcode.com/problems/meeting-rooms-ii/) · Medium · 🔒 premium
	- [Car Pooling](https://leetcode.com/problems/car-pooling/) · Medium · нюанс: событие несёт не ±1, а ±число пассажиров; высадка в `to` — отрезок полуоткрытый
	- [Corporate Flight Bookings](https://leetcode.com/problems/corporate-flight-bookings/) · Medium · нюанс: ответ нужен для каждого рейса, удобнее [[Префиксный массив#Разностный массив]]
