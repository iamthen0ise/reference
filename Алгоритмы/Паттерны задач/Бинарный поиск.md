title: Бинарный поиск
---

Поиск за O(log n): на каждом шаге отбрасываем половину оставшегося диапазона. Искать можно не только в массиве, но и в диапазоне возможных ответов (числа от `lo` до `hi`).

> [!tip] Как выбрать паттерн
> - Элементы делятся на «плохие» и «хорошие» (`плохо плохо плохо хорошо хорошо`) → **по предикату**
> - Нужны границы диапазона (первое и последнее вхождение) или задача решается двумя бинарными поисками — подготовительным и основным → **двойной бинарный поиск**
> - Иначе → **базовый бинарный поиск**

> [!note] Какие границы брать
> - **`while lo <= hi`** и `hi = mid - 1` — когда ищем конкретное значение и выходим, как только нашли. Если не нашли, `lo` — место, куда его вставить.
> - **`while lo < hi`** и `hi = mid` — когда ищем границу (первый «хороший»). Цикл заканчивается на `lo == hi`, ответ лежит в `lo`.
> - **Последний «хороший»:** берём `mid = (lo + hi + 1) // 2` и `lo = mid`. Без `+ 1` при `hi == lo + 1` получится `mid == lo`, и цикл не закончится.
> - **Короткий путь:** `bisect.bisect_left(a, x)` вернёт первую позицию, где элемент `>= x`, а `bisect.bisect_right(a, x)` — первую, где элемент `> x`.

## Базовый бинарный поиск

- **Суть:** массив отсортирован, ищем конкретный элемент или место вставки. Сравниваем середину с целью и отбрасываем половину.
- **Когда:**
	- найти значение в отсортированном массиве
	- найти позицию для вставки
- **Сложность:** T: O(log n) · S: O(1)
- **Шаблон:**
	```python
	lo, hi = 0, len(nums) - 1
	while lo <= hi:
	    mid = (lo + hi) // 2
	    if nums[mid] == target:
	        return mid
	    if nums[mid] < target:
	        lo = mid + 1
	    else:
	        hi = mid - 1
	return lo                          # не нашли: lo — позиция вставки
	# то же одной строкой: bisect.bisect_left(nums, target)
	```
- **Задачи:**
	- [Binary Search](https://leetcode.com/problems/binary-search/) · Easy
	- [Search Insert Position](https://leetcode.com/problems/search-insert-position/) · Easy

## Бинарный поиск по предикату (хорошие и плохие)

- **Суть:** в задаче есть ответ-граница: слева от неё все значения «плохие» (не подходят под условие), справа — все «хорошие» (подходят): `плохо плохо плохо хорошо хорошо`. Пишем проверку «подходит ли значение» и бинарным поиском находим, где «плохо» сменяется «хорошо». Ошибаются обычно в двух местах — в проверке и в границах: `lo` — самое маленькое значение, которое ещё может быть ответом, `hi` — самое большое.
- **Когда:**
	- в условии «минимальное X, при котором…» — ищем первый «хороший»
	- в условии «максимальное X, при котором…» — ищем последний «хороший»
	- ответ — число из диапазона, и проверить конкретное значение проще, чем вычислить ответ напрямую
	- «хорошими» и «плохими» бывают не только значения, но и индексы массива (`lo, hi = 0, len(nums) - 1`)
- **Сложность:** T: O(log(hi − lo) · C), где C — стоимость одной проверки · S: O(1)
- **Шаблон:**
	```python
	# Пример 1, первый «хороший»: Koko Eating Bananas.
	# Кучи бананов piles, охранники вернутся через h часов. С какой минимальной скоростью k (бананов в час) Коко успеет всё съесть?
	from math import ceil

	def can_finish(k):                     # «хорошая» скорость: при ней успеваем за h часов
	    return sum(ceil(p / k) for p in piles) <= h

	lo, hi = 1, max(piles)                 # меньше 1 нельзя; на max(piles) точно успеем, значит hi «хороший»
	while lo < hi:
	    mid = (lo + hi) // 2
	    if can_finish(mid):                # успеваем: ответ mid или меньше (mid оставляем, вдруг он и есть минимум)
	        hi = mid
	    else:                              # не успеваем: ответ строго больше mid
	        lo = mid + 1
	return lo                              # lo == hi: границы сошлись на минимальной скорости

	# Пример 2, последний «хороший»: Sqrt(x).
	# Нужно наибольшее целое r, при котором r * r <= n.
	lo, hi = 0, n                          # r = 0 подходит всегда, значит lo «хороший»
	while lo < hi:
	    mid = (lo + hi + 1) // 2           # +1, иначе при lo + 1 == hi цикл не закончится
	    if mid * mid <= n:                 # mid подходит: ответ mid или больше
	        lo = mid
	    else:                              # не подходит: ответ строго меньше mid
	        hi = mid - 1
	return lo
	```
- **Задачи:**
	- [First Bad Version](https://leetcode.com/problems/first-bad-version/) · Easy · нюанс: проверка уже дана, это `isBadVersion(mid)`; `lo, hi = 1, n`
	- [Sqrt(x)](https://leetcode.com/problems/sqrtx/) · Easy · нюанс: нужен последний «хороший», берём второй пример
	- [Find Minimum in Rotated Sorted Array](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/) · Medium · нюанс: ищем по индексам, `lo, hi = 0, len(nums) - 1`, «хороший» индекс — тот, где `nums[i] <= nums[-1]`
	- [Koko Eating Bananas](https://leetcode.com/problems/koko-eating-bananas/) · Medium · нюанс: это первый пример
	- [Capacity To Ship Packages Within D Days](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/) · Medium · нюанс: «хорошая» вместимость — та, при которой все грузы вывезем за `days` дней; `lo, hi = max(weights), sum(weights)`

## Двойной бинарный поиск

- **Суть:** бинарный поиск запускаем дважды. Либо отдельно для левой и правой границы (первое и последнее вхождение), либо так: сначала подготовительный поиск находит точку разрыва, нужную строку или границу, потом основной ищет сам ответ.
- **Когда:**
	- найти первое и последнее вхождение значения
	- решение раскладывается на два бинарных поиска, подготовительный и основной: найти pivot в повёрнутом массиве и искать с учётом сдвига, выбрать строку в матрице и искать в ней
- **Сложность:** T: O(log n) · S: O(1)
- **Шаблон:**
	```python
	# вариант А: две границы — первое и последнее вхождение
	# Пример: nums = [5, 7, 7, 8, 8, 10], target = 8 → ответ [3, 4] (первое и последнее вхождение)
	def bound(nums, target, first):
	    lo, hi, res = 0, len(nums) - 1, -1
	    while lo <= hi:
	        mid = (lo + hi) // 2
	        if nums[mid] == target:
	            res = mid
	            if first:
	                hi = mid - 1           # нашли, ищем ещё левее
	            else:
	                lo = mid + 1           # нашли, ищем ещё правее
	        elif nums[mid] < target:
	            lo = mid + 1
	        else:
	            hi = mid - 1
	    return res

	left, right = bound(nums, target, True), bound(nums, target, False)   # -1, -1, если значения нет
	# то же через bisect: l = bisect_left(nums, target); r = bisect_right(nums, target) - 1; значения нет → l > r

	# вариант Б: подготовительный поиск + основной (Search in Rotated Sorted Array)
	# Пример: nums = [4, 5, 6, 7, 0, 1, 2], target = 0 → ответ 4. Массив отсортирован и сдвинут по кругу
	n = len(nums)
	lo, hi = 0, n - 1
	while lo < hi:                         # 1) подготовительный: ищем индекс минимума (pivot), здесь это 4
	    mid = (lo + hi) // 2
	    if nums[mid] <= nums[-1]:
	        hi = mid
	    else:
	        lo = mid + 1
	pivot = lo

	lo, hi = pivot, pivot + n - 1          # 2) основной: обычный поиск, индексы сдвинуты на pivot
	while lo <= hi:
	    mid = (lo + hi) // 2
	    v = nums[mid % n]
	    if v == target:
	        return mid % n
	    if v < target:
	        lo = mid + 1
	    else:
	        hi = mid - 1
	return -1
	```
- **Задачи:**
	- [Find First and Last Position of Element in Sorted Array](https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/) · Medium · вариант А
	- [Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/) · Medium · вариант Б
	- [Search a 2D Matrix](https://leetcode.com/problems/search-a-2d-matrix/) · Medium · нюанс: сначала ищем строку (сравнивая с её первым и последним элементом), потом ищем в этой строке. Можно и одним поиском по номеру `i` от 0 до `rows * cols - 1`: элемент — `matrix[i // cols][i % cols]`
