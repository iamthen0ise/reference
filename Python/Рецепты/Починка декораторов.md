## Потеряны имя и сигнатура

Обёртка без `functools.wraps` возвращает функцию по имени `wrapper`: исчезают `__name__`, `__doc__`, `__wrapped__` и настоящая сигнатура. Всё, что читает функцию снаружи, видит чужую. Логи и профайлер показывают `wrapper`, `inspect.signature` отдаёт `(*args, **kwargs)`, а контейнеры зависимостей и фикстуры pytest строят вызов по сигнатуре, поэтому настоящих параметров не находят. В блоке `params_for_injection` делает то же, что они: читает имена параметров.

```python
import functools
import inspect
from collections.abc import Callable
from typing import Any


def naive(func: Callable[..., Any]) -> Callable[..., Any]:
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        return func(*args, **kwargs)

    return wrapper


def fixed(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        return func(*args, **kwargs)

    return wrapper


@naive
def total_naive(price: float, qty: int = 1) -> float:
    """Сумма строки заказа."""
    return price * qty


@fixed
def total_fixed(price: float, qty: int = 1) -> float:
    """Сумма строки заказа."""
    return price * qty


def params_for_injection(func: Callable[..., Any]) -> list[str]:
    # так делают контейнеры зависимостей и фикстуры: читают сигнатуру
    return list(inspect.signature(func).parameters)


for f in (total_naive, total_fixed):
    print(
        f.__name__,
        "|",
        f.__doc__,
        "|",
        inspect.signature(f),
        "|",
        hasattr(f, "__wrapped__"),
        "|",
        params_for_injection(f),
    )
```

```text title="Вывод"
wrapper | None | (*args: Any, **kwargs: Any) -> Any | False | ['args', 'kwargs']
total_fixed | Сумма строки заказа. | (price: float, qty: int = 1) -> float | True | ['price', 'qty']
```

**Как заметить.** Печать `__name__` и `inspect.signature(func)` у декорированной функции. В тесте это три строки, они есть ниже в разделе [[#Тест для любого декоратора]].

**Исправление.** `@functools.wraps(func)` на обёртке: он копирует имя, документацию, аннотации и кладёт исходную функцию в `__wrapped__`, а `inspect.signature` идёт по `__wrapped__` до оригинала. Подробнее: раздел «Наивный декоратор и functools.wraps» заметки [[Декораторы]].

## Синхронная обёртка на async def

`async def` при вызове не выполняется, а возвращает корутину. Обычная обёртка получает эту корутину, мгновенно останавливает секундомер и отдаёт её дальше. Замер показывает около нуля, а `except` в обёртке не видит исключений: они вылетят позже, там, где кто-то сделает `await`. В блоке функция спит 0.2 секунды и падает.

```python
import asyncio
import functools
import inspect
import time
from collections.abc import Awaitable, Callable
from typing import Any

SLEEP_S = 0.2


def timed_sync(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)  # вернёт корутину, но не выполнит её
        except ValueError:
            print("  обёртка увидела ValueError")  # сюда не попадём
            raise
        finally:
            print(f"  замер: {(time.perf_counter() - start) * 1000:.1f} мс")

    return wrapper


def timed_async(func: Callable[..., Awaitable[Any]]) -> Callable[..., Awaitable[Any]]:
    @functools.wraps(func)
    async def wrapper(*args: Any, **kwargs: Any) -> Any:
        start = time.perf_counter()
        try:
            return await func(*args, **kwargs)
        except ValueError:
            print("  обёртка увидела ValueError")
            raise
        finally:
            print(f"  замер: {(time.perf_counter() - start) * 1000:.1f} мс")

    return wrapper


async def slow_ok() -> str:
    await asyncio.sleep(SLEEP_S)
    return "ok"


async def slow_fail() -> str:
    await asyncio.sleep(SLEEP_S)
    raise ValueError("boom")


async def main() -> None:
    for label, deco in (("синхронная обёртка", timed_sync), ("async-обёртка", timed_async)):
        print(label)
        print("  это корутинная функция:", inspect.iscoroutinefunction(deco(slow_ok)))
        print("  результат:", await deco(slow_ok)())
        try:
            await deco(slow_fail)()
        except ValueError as exc:
            print("  вызывающий получил:", repr(exc))


asyncio.run(main())
```

```text title="Вывод"
синхронная обёртка
  это корутинная функция: False
  замер: 0.0 мс
  результат: ok
  замер: 0.0 мс
  вызывающий получил: ValueError('boom')
async-обёртка
  это корутинная функция: True
  замер: 201.2 мс
  результат: ok
  обёртка увидела ValueError
  замер: 201.4 мс
  вызывающий получил: ValueError('boom')
```

Число 201 мс чуть плавает от запуска к запуску, остальное стабильно.

**Как заметить.** Замер пропорционален нулю, а не работе. Ещё признак: `inspect.iscoroutinefunction(обёртка)` даёт `False`, хотя исходная функция асинхронная. Фреймворки, которые решают по этому признаку, как запускать функцию, ошибутся.

**Исправление.** Развилка по типу функции и своя `async def` обёртка с `await` внутри `try`. В эталоне это сделано через `inspect.iscoroutinefunction`. Разбор в разделе [[Декораторы#Синхронный и асинхронный декоратор]].

## Обёртка на генераторе

С генератором то же самое, только вместо корутины возвращается объект-генератор. Тело функции не работало ни секунды: оно стартует с первого `next()`. Обёртка меряет создание объекта (около 0 мс), а ошибка внутри итерации уходит мимо её `try/except`. В блоке генератор делает три шага по 50 мс и на третьем падает.

```python
import functools
import time
from collections.abc import Callable, Generator, Iterator
from typing import Any

STEP_S = 0.05


def timed_naive(func: Callable[..., Iterator[int]]) -> Callable[..., Iterator[int]]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Iterator[int]:
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)  # только создали генератор
        except ValueError:
            print("  обёртка увидела ValueError")  # не сработает
            raise
        finally:
            print(f"  замер: {(time.perf_counter() - start) * 1000:.1f} мс")

    return wrapper


def timed_gen(func: Callable[..., Generator[int, Any, Any]]) -> Callable[..., Generator[int, Any, Any]]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Generator[int, Any, Any]:
        start = time.perf_counter()
        try:
            return (yield from func(*args, **kwargs))
        except ValueError:
            print("  обёртка увидела ValueError")
            raise
        finally:
            print(f"  замер: {(time.perf_counter() - start) * 1000:.1f} мс")

    return wrapper


def numbers(count: int) -> Generator[int, None, None]:
    for i in range(count):
        time.sleep(STEP_S)
        if i == 2:
            raise ValueError("битый элемент")
        yield i


for label, deco in (("обёртка-функция", timed_naive), ("обёртка-генератор", timed_gen)):
    print(label)
    got: list[int] = []
    try:
        for item in deco(numbers)(5):
            got.append(item)
    except ValueError as exc:
        print("  вызывающий получил:", repr(exc), "после элементов", got)
```

```text title="Вывод"
обёртка-функция
  замер: 0.0 мс
  вызывающий получил: ValueError('битый элемент') после элементов [0, 1]
обёртка-генератор
  обёртка увидела ValueError
  замер: 157.7 мс
  вызывающий получил: ValueError('битый элемент') после элементов [0, 1]
```

Время 160 мс чуть плавает.

**Как заметить.** Тот же ноль в замере и «обёртка не увидела» ошибку, которую видит вызывающий. Тест: пустить генератор через `list(...)` и сравнить замер с реальной длительностью.

**Исправление.** Сделать саму обёртку генератором и делегировать через `yield from`: тогда замер и `try/except` живут столько же, сколько итерация, а `send`, `throw` и `close` доходят до исходного генератора. Для async-генератора `yield from` нет, и в эталоне нужен ручной цикл (см. ниже). Что такое генератор и `yield from`: [[Итераторы и генераторы]].

## Проглоченное исключение

`except Exception: return None` «чтобы не падало» превращает ошибку в значение. Причина теряется, а `None` едет дальше и падает или, хуже, молча записывается в базу, далеко от места поломки.

```python
import functools
import logging
import sys
from collections.abc import Callable
from typing import Any

logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s", stream=sys.stdout)
log = logging.getLogger("demo")


def safe(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        try:
            return func(*args, **kwargs)
        except Exception:
            return None  # «чтобы не падало»

    return wrapper


def logged(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        try:
            return func(*args, **kwargs)
        except Exception as exc:
            log.error("%s упала: %r", func.__qualname__, exc)
            raise  # то же исключение, тот же тип

    return wrapper


def parse_price(text: str) -> float:
    return float(text)


price = safe(parse_price)("12,5")
print("safe вернул:", price)
try:
    print("итог:", price * 2)
except TypeError as exc:
    print("упало далеко от причины:", exc)

try:
    logged(parse_price)("12,5")
except ValueError as exc:
    print("logged пробросил:", repr(exc))
```

```text title="Вывод"
safe вернул: None
упало далеко от причины: unsupported operand type(s) for *: 'NoneType' and 'int'
ERROR parse_price упала: ValueError("could not convert string to float: '12,5'")
logged пробросил: ValueError("could not convert string to float: '12,5'")
```

**Как заметить.** В логах пусто, а `NoneType` встречается там, где его не ждали. Поиск по коду: `return None` или `pass` внутри `except` в обёртках.

**Исправление.** Декоратор не решает за вызывающего, что делать с ошибкой: он логирует и пробрасывает дальше тем же исключением (`raise` без аргументов сохраняет тип, сообщение и traceback). Значение по умолчанию нужно только в конкретном месте и только на конкретную ошибку, это решение вызывающего кода, а не обёртки. Если выше по стеку ошибку тоже логируют, одна ошибка попадёт в лог дважды: тогда оставьте логирование в одном слое. См. [[Исключения]].

## Состояние в замыкании

Переменная, объявленная не там, живёт не столько, сколько вы думаете. Словарь на уровне модуля общий для всех декорированных функций, и счётчик у `a` и `b` один. Кэш, который хранит одно значение без ключа, отдаёт его на любые аргументы.

```python
import functools
from collections.abc import Callable
from typing import Any

stats = {"calls": 0}  # одна на весь модуль, а не на функцию


def counted_shared(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        stats["calls"] += 1
        return func(*args, **kwargs)

    return wrapper


per_func: dict[str, int] = {}  # ключ — имя функции


def counted(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        per_func[func.__qualname__] = per_func.get(func.__qualname__, 0) + 1
        return func(*args, **kwargs)

    return wrapper


def cached_no_key(func: Callable[..., Any]) -> Callable[..., Any]:
    cache: dict[str, Any] = {}

    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        if "value" not in cache:
            cache["value"] = func(*args, **kwargs)
        return cache["value"]  # одно значение на любые аргументы

    return wrapper


@counted_shared
def a() -> None: ...


@counted_shared
def b() -> None: ...


@counted
def c() -> None: ...


@counted
def d() -> None: ...


@cached_no_key
def square_wrong(x: int) -> int:
    return x * x


@functools.cache  # ключ — сами аргументы
def square(x: int) -> int:
    return x * x


a()
b()
b()
c()
d()
d()
print("общий счётчик:", stats, "| по функциям:", per_func)
print("кэш без ключа:", square_wrong(2), square_wrong(3))
print("functools.cache:", square(2), square(3))
```

```text title="Вывод"
общий счётчик: {'calls': 3} | по функциям: {'c': 1, 'd': 2}
кэш без ключа: 4 4
functools.cache: 4 9
```

**Как заметить.** Вызвать две разные функции и убедиться, что счётчики независимы; вызвать кэшируемую с разными аргументами. Это два однострочных теста.

**Исправление.** Состояние создаётся внутри `decorate` и привязано к конкретной функции, а ключ кэша строится из аргументов. Для кэша проще взять `functools.cache` (аргументы должны быть хешируемы); на методах он держит ссылку на `self`, поэтому объект не освобождается, пока жив кэш. Если декорированную функцию зовут из нескольких потоков, `+= 1` на общем счётчике не атомарен и нужен `Lock`. Про области видимости и `nonlocal`: [[Области видимости и замыкания]].

## Декоратор с параметрами без скобок

Фабрика декораторов `tag(label)` вызывается дважды: `tag("x")` возвращает декоратор, и уже он принимает функцию. Если написать `@tag_naive` без скобок, функция уйдёт в параметр `label`, и вместо функции в имени останется внутренний декоратор. Он ждёт функцию, и вызов `hello("мир")` ничего не выполняет, а молча возвращает новую функцию.

```python
import functools
from collections.abc import Callable
from typing import Any


def tag_naive(label: str = "call") -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    def decorate(func: Callable[..., Any]) -> Callable[..., Any]:
        @functools.wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            print(f"[{label}] {func.__name__}")
            return func(*args, **kwargs)

        return wrapper

    return decorate


def tag(func: Callable[..., Any] | None = None, /, *, label: str = "call") -> Any:
    def decorate(f: Callable[..., Any]) -> Callable[..., Any]:
        @functools.wraps(f)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            print(f"[{label}] {f.__name__}")
            return f(*args, **kwargs)

        return wrapper

    if func is None:  # вызвали со скобками: @tag() или @tag(label="x")
        return decorate
    return decorate(func)  # вызвали без скобок: @tag


@tag_naive  # забыли скобки
def hello(name: str) -> str:
    return f"привет, {name}"


result = hello("мир")
print("hello('мир') вернул:", result)
print("тело hello не выполнялось, строки [call] нет")


@tag
def one(x: int) -> int:
    return x


@tag()
def two(x: int) -> int:
    return x


@tag(label="custom")
def three(x: int) -> int:
    return x


print(one(1), two(2), three(3))
```

```text title="Вывод"
hello('мир') вернул: <function tag_naive.<locals>.decorate.<locals>.wrapper at 0x...>
тело hello не выполнялось, строки [call] нет
[call] one
[call] two
[custom] three
1 2 3
```

Адрес объекта в первой строке меняется от запуска к запуску.

**Как заметить.** Результат вызова оказывается функцией, а тело не отработало. Ловят по результату: проверка «вызов вернул функцию» в тесте.

**Исправление.** Принимать функцию необязательным позиционным первым аргументом, а параметры делать только именованными (`*`). Если функцию передали, декорировать сразу; если нет, вернуть декоратор. Работают `@tag`, `@tag()` и `@tag(label="x")`. Для типов такая сигнатура требует `overload`, и это уже повод задуматься, нужно ли поддерживать оба вида. Эталонный `measured` ниже намеренно принимает только `@measured()`: параметры в нём только именованные, и `@measured` без скобок падает сразу с `TypeError`, а не молча портит функцию.

## Порядок со staticmethod, classmethod и property

`@staticmethod`, `@classmethod` и `@property` создают объекты-дескрипторы, а не функции. Свой декоратор, поставленный над ними, получает не функцию, а этот объект, и обёртка превращается в обычный метод. Дескрипторы описаны в заметке [[Атрибуты и дескрипторы]]. Печатаются результаты вызова всех четырёх способов у класса с неправильным порядком (`Bad`) и правильным (`Good`).

```python
import functools
from collections.abc import Callable
from typing import Any


def logged(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        print(f"  вызов {func.__name__}")
        return func(*args, **kwargs)

    return wrapper


def attempt(label: str, action: Callable[[], Any]) -> None:
    try:
        print(f"{label} ->", action())
    except Exception as exc:
        print(f"{label} -> {type(exc).__name__}: {exc}")


class Bad:
    @logged
    @staticmethod
    def helper(x: int) -> int:
        return x * 2

    @logged
    @classmethod
    def make(cls) -> str:
        return cls.__name__

    @logged
    @property
    def size(self) -> int:
        return 3


class Good:
    @staticmethod
    @logged
    def helper(x: int) -> int:
        return x * 2

    @classmethod
    @logged
    def make(cls) -> str:
        return cls.__name__

    @property
    @logged
    def size(self) -> int:
        return 3


for cls in (Bad, Good):
    print(cls.__name__)
    attempt("  Class.helper(2)", lambda: cls.helper(2))
    attempt("  Class().helper(2)", lambda: cls().helper(2))
    attempt("  Class.make()", lambda: cls.make())
    attempt("  Class().size", lambda: cls().size)
```

```text title="Вывод"
Bad
  вызов helper
  Class.helper(2) -> 4
  вызов helper
  Class().helper(2) -> TypeError: Bad.helper() takes 1 positional argument but 2 were given
  вызов make
  Class.make() -> TypeError: 'classmethod' object is not callable
  Class().size -> <bound method logged.<locals>.wrapper of <__main__.Bad object at 0x...>>
Good
  вызов helper
  Class.helper(2) -> 4
  вызов helper
  Class().helper(2) -> 4
  вызов make
  Class.make() -> Good
  вызов size
  Class().size -> 3
```

Адрес объекта во второй колонке последней строки `Bad` меняется от запуска к запуску. Подпись «Class» заменяет имя класса из цикла.

**Как заметить.** Ошибки вида «`'classmethod' object is not callable`» или «takes 1 positional argument but 2 were given» только у экземпляра; `property`, ставший методом, вообще не падает: `obj.size` вернёт привязанный метод вместо числа.

**Исправление.** Встроенный дескриптор всегда самый внешний: `@staticmethod`, `@classmethod` или `@property` сверху, свой декоратор под ним. Он тогда декорирует обычную функцию, а дескриптор потом оборачивает результат.

## Побочный эффект при импорте

Тело декоратора выполняется в момент `def`, то есть при импорте модуля, а не при вызове функции. Открытое соединение, чтение конфига или `tracemalloc.start()` на этом месте случаются при любом импорте, в том числе в тестах и в утилитах, которые ничего не вызывают.

```python
import functools
from collections.abc import Callable
from typing import Any


def heavy_init() -> str:
    print("  ...открываем соединение, читаем конфиг")
    return "ресурс"


def eager(func: Callable[..., Any]) -> Callable[..., Any]:
    resource = heavy_init()  # выполнится при объявлении функции

    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        return func(*args, resource=resource, **kwargs)

    return wrapper


def lazy(func: Callable[..., Any]) -> Callable[..., Any]:
    @functools.cache  # один раз, при первом вызове
    def get_resource() -> str:
        return heavy_init()

    @functools.wraps(func)
    def wrapper(*args: Any, **kwargs: Any) -> Any:
        return func(*args, resource=get_resource(), **kwargs)

    return wrapper


print("начало тела модуля")


@eager
def a(*, resource: str) -> str:
    return resource


print("eager объявлен, ни одного вызова не было")


@lazy
def b(*, resource: str) -> str:
    return resource


print("lazy объявлен, тишина")
print("первый вызов b:")
b()
print("второй вызов b:")
b()
```

```text title="Вывод"
начало тела модуля
  ...открываем соединение, читаем конфиг
eager объявлен, ни одного вызова не было
lazy объявлен, тишина
первый вызов b:
  ...открываем соединение, читаем конфиг
второй вызов b:
```

**Как заметить.** `python -X importtime` показывает медленные импорты, а `python -c "import модуль"` не должен ничего печатать и открывать. См. [[Импорт и модули]].

**Исправление.** Тяжёлое откладывать на первый вызов (в блоке для этого `functools.cache`: два потока на самом первом вызове могут запустить инициализацию дважды, для потоков нужен `Lock`). Регистрация функции в реестре при объявлении допустима, если это дешёвая и идемпотентная операция, но не соединение и не чтение файла.

## Часы, которые идут назад

`time.time()` показывает настенное время, его переводят: синхронизация NTP, ручная правка. Замер через разность двух `time.time()` может получиться нулевым или отрицательным. Для длительностей нужны часы, которые не идут назад.

```python
import functools
import time
from collections.abc import Callable
from typing import Any
from unittest import mock


def timed(clock: Callable[[], float]) -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    def decorate(func: Callable[..., Any]) -> Callable[..., Any]:
        @functools.wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            start = clock()
            try:
                return func(*args, **kwargs)
            finally:
                print(f"  замер: {(clock() - start) * 1000:.0f} мс")

        return wrapper

    return decorate


def job() -> None:
    pass


for name in ("time", "perf_counter"):
    info = time.get_clock_info(name)
    print(f"{name}: monotonic={info.monotonic}, adjustable={info.adjustable}")

# Модель: во время вызова системные часы перевели на секунду назад (NTP, ручная правка).
# Реально этого не повторить по заказу, поэтому подменяем time.time вручную.
with mock.patch("time.time", side_effect=[1_000.0, 999.0]):
    print("time.time:")
    timed(lambda: time.time())(job)()
print("perf_counter:")
timed(time.perf_counter)(job)()
```

```text title="Вывод"
time: monotonic=False, adjustable=True
perf_counter: monotonic=True, adjustable=False
time.time:
  замер: -1000 мс
perf_counter:
  замер: 0 мс
```

Сдвиг часов здесь смоделирован: `time.time` подменён так, что во время вызова он «возвращает назад» на секунду, потому что настоящий сдвиг по заказу не воспроизвести. Первые две строки получены на самих часах, без подмены.

**Как заметить.** В логах время вызова ноль или минус, редко и без видимой причины. Корень виден в первой строке вывода: `monotonic=False` у `time`.

**Исправление.** `time.perf_counter()` для длительностей: часы монотонные и с лучшим разрешением. `time.time()` оставить для меток «когда это случилось».

## Повтор неидемпотентной операции

Декоратор повтора при таймауте кажется безобидным. Но таймаут означает «ответ не пришёл», а не «операция не выполнилась»: сервер мог списать деньги, а ответ потерялся. Повтор такого вызова делает вторую операцию. В блоке «сервер» принимает платёж, записывает его и после этого теряет ответ в первый раз.

```python
import functools
from collections.abc import Callable
from typing import Any

attempts = 0
charged: dict[str, int] = {}  # «база платёжного сервиса»: ключ -> сколько списали


def retry(times: int, on: tuple[type[BaseException], ...] = (TimeoutError,)) -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    def decorate(func: Callable[..., Any]) -> Callable[..., Any]:
        @functools.wraps(func)
        def wrapper(*args: Any, **kwargs: Any) -> Any:
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except on:
                    if attempt == times - 1:
                        raise
            raise AssertionError("недостижимо")

        return wrapper

    return decorate


def server_charge(order_id: str, amount: int, idempotency_key: str | None) -> None:
    """Сервер списывает деньги; ответ теряется по пути (первый раз)."""
    global attempts
    attempts += 1
    key = idempotency_key or f"no-key-{attempts}"
    charged.setdefault(key, amount)  # с ключом повтор не спишет второй раз
    if attempts == 1:
        raise TimeoutError("ответ потерян")


@retry(times=3)
def charge_blind(order_id: str, amount: int) -> None:
    server_charge(order_id, amount, None)


@retry(times=3)
def charge_keyed(order_id: str, amount: int, key: str) -> None:
    server_charge(order_id, amount, key)


charge_blind("A-1", 100)
print("без ключа: попыток", attempts, "списано", sum(charged.values()))

attempts = 0
charged.clear()
charge_keyed("A-2", 100, key="order-A-2")  # ключ задан один раз, до повторов
print("с ключом:  попыток", attempts, "списано", sum(charged.values()))
```

```text title="Вывод"
без ключа: попыток 2 списано 200
с ключом:  попыток 2 списано 100
```

**Как заметить.** Дубли в данных после сетевых сбоев: две записи на одну операцию, повторные письма и списания. Ищите `retry` над функцией, которая что-то создаёт или изменяет.

**Исправление.** Три правила, в таком порядке. Первое: не вешать повтор на неидемпотентную операцию. Второе: если повторять нужно, операция получает ключ идемпотентности, который создают один раз до первой попытки и передают во все повторы (в блоке `charge_keyed`: сервер видит тот же ключ и не списывает второй раз; на реальном сервисе такой ключ должен поддерживаться самим API). Третье: повторять только по узкому списку ошибок (`TimeoutError`, а не `Exception`), с лимитом и паузой между попытками. Задержку с экспоненциальным ростом смотрите в разделе «Декоратор с параметрами: повтор при ошибках с экспоненциальной задержкой» заметки [[Декораторы]]; здесь она убрана, чтобы не мешать смыслу.

## Эталон: замер одной функцией

Готовый декоратор, который меряет `def`, `async def`, генератор и async-генератор и пишет в лог одну строку на вызов: имя функции, исход (`ok`, имя исключения или `closed`), стену в мс, CPU в мс и при `memory=True` пик памяти в КиБ. Использование: `@measured()` и `@measured(memory=True)`. Результат функции возвращается как был, исключения проходят наружу без изменений.

Решения, которые стоит знать до копирования:

- **Тип функции** определяется один раз при декорировании через `inspect.iscoroutinefunction`, `inspect.isgeneratorfunction` и `inspect.isasyncgenfunction`. Проверки не пересекаются: async-генератор не считается корутинной функцией, и наоборот.
- **Генераторы** меряются целиком, от первого `next()` до конца итерации. Ранний выход потребителя (`close()` у генератора, `aclose()` у async-генератора) тоже пишет строку, с исходом `closed`. Генератор, у которого не вызвали ни одного `next()`, ничего не пишет: его тело не стартовало. Стена включает паузы потребителя между элементами, а не только работу внутри генератора.
- **Отмена.** В `async def` отмена задачи (`CancelledError`) попадает в `except BaseException`, исход записывается как `CancelledError`, исключение уходит дальше. Отмену не глотаем.
- **CPU** считает `time.process_time()`: время процессора всего процесса, всех потоков и всех задач. Для функции, которая работает рядом с другими задачами, оно включает и чужую работу.
- **Память** при `memory=True` через `tracemalloc`. Он хранит трейс каждого выделения и замедляет программу, поэтому включать его нужно на время диагностики, а не навсегда. Пик общий на процесс: параллельные замеры с `memory=True` портят числа друг другу, а `measured` останавливает `tracemalloc` только если сам его включил.
- **Типизация** через `ParamSpec`: сигнатура декорированной функции видна типизатору как у исходной. Внутри ветки возвращают `cast`: типизатор не может связать `R` с обёрткой другого вида, а снаружи сигнатура остаётся честной.
- **Логгер:** берётся из аргумента или по имени модуля функции, формат и уровень задаёт приложение. Про настройку: [[Логирование]].

Файл целиком; сохраните его как `measured.py` (тест ниже импортирует его). Запуск `python3 measured.py` печатает демонстрацию, `import measured` ничего не печатает. Там же `measure_block(name)`: тот же замер для блока кода, как контекстный менеджер.

```python
import asyncio
import functools
import inspect
import logging
import time
import tracemalloc
from collections.abc import AsyncGenerator, Callable, Generator, Iterator
from contextlib import contextmanager
from typing import Any, ParamSpec, TypeVar, cast

P = ParamSpec("P")
R = TypeVar("R")

BYTES_IN_KIB = 1024
MS = 1000.0


class _Probe:
    """Один замер: стена, CPU, при желании пик памяти. Пишет ровно одну строку."""

    def __init__(self, label: str, memory: bool, log: logging.Logger) -> None:
        self.label = label
        self.memory = memory
        self.log = log

    def start(self) -> None:
        self.owns_tracing = False
        if self.memory:
            if not tracemalloc.is_tracing():
                tracemalloc.start()
                self.owns_tracing = True
            tracemalloc.reset_peak()
            self.base_bytes = tracemalloc.get_traced_memory()[0]
        self.wall0 = time.perf_counter()
        self.cpu0 = time.process_time()

    def finish(self, outcome: str) -> None:
        wall_ms = (time.perf_counter() - self.wall0) * MS
        cpu_ms = (time.process_time() - self.cpu0) * MS
        extra = ""
        if self.memory:
            peak_kib = (tracemalloc.get_traced_memory()[1] - self.base_bytes) / BYTES_IN_KIB
            if self.owns_tracing:
                tracemalloc.stop()
            extra = f" peak_kib={peak_kib:.0f}"
        self.log.info("%s outcome=%s wall_ms=%.1f cpu_ms=%.1f%s", self.label, outcome, wall_ms, cpu_ms, extra)


def _outcome(exc: BaseException) -> str:
    # GeneratorExit — не ошибка, а ранний выход потребителя (close/aclose)
    return "closed" if isinstance(exc, GeneratorExit) else type(exc).__name__


def measured(
    *, memory: bool = False, logger: logging.Logger | None = None
) -> Callable[[Callable[P, R]], Callable[P, R]]:
    """Замер вызова: def, async def, генератор и async-генератор. Исключения идут дальше как были."""

    def decorate(func: Callable[P, R]) -> Callable[P, R]:
        label = func.__qualname__
        log = logger or logging.getLogger(func.__module__)

        def probe() -> _Probe:
            return _Probe(label, memory, log)

        if inspect.isasyncgenfunction(func):

            @functools.wraps(func)
            async def agen_wrapper(*args: Any, **kwargs: Any) -> AsyncGenerator[Any, Any]:
                p, outcome = probe(), "ok"
                p.start()
                inner = func(*args, **kwargs)
                try:
                    try:
                        value = await anext(inner)
                        while True:
                            try:
                                sent = yield value
                            except GeneratorExit:  # aclose(): закрыть и внутренний
                                await inner.aclose()
                                raise
                            except BaseException as exc:  # athrow(): передать внутрь
                                value = await inner.athrow(exc)
                            else:
                                value = await inner.asend(sent)
                    except StopAsyncIteration:
                        pass
                except BaseException as exc:
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], agen_wrapper)

        if inspect.isgeneratorfunction(func):

            @functools.wraps(func)
            def gen_wrapper(*args: Any, **kwargs: Any) -> Generator[Any, Any, Any]:
                p, outcome = probe(), "ok"
                p.start()  # тело генератора стартует с первого next()
                try:
                    return (yield from func(*args, **kwargs))
                except BaseException as exc:
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], gen_wrapper)

        if inspect.iscoroutinefunction(func):

            @functools.wraps(func)
            async def async_wrapper(*args: Any, **kwargs: Any) -> Any:
                p, outcome = probe(), "ok"
                p.start()
                try:
                    return await func(*args, **kwargs)
                except BaseException as exc:  # включая CancelledError
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], async_wrapper)

        @functools.wraps(func)
        def sync_wrapper(*args: Any, **kwargs: Any) -> Any:
            p, outcome = probe(), "ok"
            p.start()
            try:
                return func(*args, **kwargs)
            except BaseException as exc:
                outcome = _outcome(exc)
                raise
            finally:
                p.finish(outcome)

        return cast(Callable[P, R], sync_wrapper)

    return decorate


@contextmanager
def measure_block(name: str) -> Iterator[None]:
    """То же для блока кода: with measure_block("разбор файла"): ..."""
    p, outcome = _Probe(name, False, logging.getLogger(__name__)), "ok"
    p.start()
    try:
        yield
    except BaseException as exc:
        outcome = _outcome(exc)
        raise
    finally:
        p.finish(outcome)


if __name__ == "__main__":
    import sys

    logging.basicConfig(level=logging.INFO, format="%(message)s", stream=sys.stdout)

    @measured()
    def crunch(n: int) -> int:
        return sum(i * i for i in range(n))

    @measured(memory=True)
    def build_list(n: int) -> int:
        return len([0] * n)

    @measured()
    async def fetch(delay: float) -> str:
        await asyncio.sleep(delay)
        return "данные"

    @measured()
    def numbers(count: int) -> Generator[int, None, None]:
        for i in range(count):
            time.sleep(0.02)
            yield i

    @measured()
    async def ticks(count: int) -> AsyncGenerator[int, None]:
        for i in range(count):
            await asyncio.sleep(0.02)
            yield i

    @measured()
    def broken() -> None:
        raise ValueError("упала")

    async def main() -> None:
        print("sync:", crunch(300_000))
        print("sync + память:", build_list(1_000_000))
        print("async:", await fetch(0.1))
        print("генератор:", list(numbers(3)))
        print("async-генератор:", [x async for x in ticks(3)])
        try:
            broken()
        except ValueError as exc:
            print("вызывающий получил:", repr(exc))
        gen = numbers(10)
        print("ранний выход, первый элемент:", next(gen))
        gen.close()
        agen = ticks(10)
        print("ранний выход, первый элемент:", await anext(agen))
        await agen.aclose()
        with measure_block("блок"):
            time.sleep(0.05)

    asyncio.run(main())
```

```text title="Вывод"
crunch outcome=ok wall_ms=8.1 cpu_ms=8.1
sync: 8999955000050000
build_list outcome=ok wall_ms=1.1 cpu_ms=1.1 peak_kib=7813
sync + память: 1000000
fetch outcome=ok wall_ms=101.1 cpu_ms=0.1
async: данные
numbers outcome=ok wall_ms=75.1 cpu_ms=0.1
генератор: [0, 1, 2]
ticks outcome=ok wall_ms=62.6 cpu_ms=0.5
async-генератор: [0, 1, 2]
broken outcome=ValueError wall_ms=0.0 cpu_ms=0.0
вызывающий получил: ValueError('упала')
ранний выход, первый элемент: 0
numbers outcome=closed wall_ms=20.7 cpu_ms=0.1
ранний выход, первый элемент: 0
ticks outcome=closed wall_ms=21.2 cpu_ms=0.2
блок outcome=ok wall_ms=52.1 cpu_ms=0.1
```

Числа wall, cpu и peak у вас будут другие: время плавает, 7813 КиБ около восьми мегабайт под миллион указателей. Порядок строк как на терминале: строка лога выходит раньше `print` с результатом, потому что `print` получает значение после возврата из функции. В строках `closed` видно, что замер генератора записался и при раннем выходе. Пик памяти считается от значения на входе, а не от нуля.

На 3.12 вывод по строкам такой же, различаются только числа.

## Тест для любого декоратора

Тест проверяет то, что ломается чаще всего: имя и `__wrapped__`, сигнатуру, то что `async def` остаётся корутинной функцией, прохождение исключения тем же объектом и то, что генератор отдаёт те же элементы. Заодно проверяет, что ранний выход потребителя доходит до `finally` исходного генератора. Файл целиком; положите рядом `measured.py` из прошлого раздела и запустите во временном окружении (`uv venv`, `pip install pytest` или `uv run --no-project --with pytest python -m pytest -q test_decorator_contract.py`).

Чтобы проверить свой декоратор, замените тело `make()`: оно должно вернуть декоратор, готовый к применению.

```python
import asyncio
import importlib
import inspect
import os
from collections.abc import AsyncGenerator, Awaitable, Callable, Generator
from typing import Any

import pytest

# Какой декоратор проверяем: модуль задаётся переменной окружения.
# Для своего декоратора замените тело make().
_module = importlib.import_module(os.environ.get("DECORATOR_MODULE", "measured"))


def make() -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    return _module.measured()


BOOM = ValueError("boom")


def plain(a: int, b: int = 2) -> int:
    """Складывает."""
    return a + b


async def coro(a: int, b: int = 2) -> int:
    """Складывает асинхронно."""
    await asyncio.sleep(0)
    return a + b


def gen(n: int = 3) -> Generator[int, None, None]:
    """Отдаёт числа."""
    yield from range(n)


async def agen(n: int = 3) -> AsyncGenerator[int, None]:
    """Отдаёт числа асинхронно."""
    for i in range(n):
        await asyncio.sleep(0)
        yield i


def plain_fail() -> None:
    raise BOOM


async def coro_fail() -> None:
    raise BOOM


def gen_fail() -> Generator[int, None, None]:
    yield 1
    raise BOOM


async def agen_fail() -> AsyncGenerator[int, None]:
    yield 1
    raise BOOM


ALL = [plain, coro, gen, agen]
FAILING = [plain_fail, coro_fail, gen_fail, agen_fail]


async def _drain_async(agen_obj: AsyncGenerator[int, None]) -> list[int]:
    return [x async for x in agen_obj]


async def _await(aw: Awaitable[Any]) -> Any:
    return await aw


def run(func: Callable[..., Any], *args: Any) -> Any:
    """Вызвать функцию любого из четырёх видов и вернуть итог целиком."""
    obj = func(*args)
    if inspect.isasyncgen(obj):
        return asyncio.run(_drain_async(obj))
    if inspect.isgenerator(obj):
        return list(obj)
    if inspect.iscoroutine(obj):
        return asyncio.run(_await(obj))
    return obj


@pytest.mark.parametrize("func", ALL)
def test_name_doc_and_wrapped(func: Callable[..., Any]) -> None:
    wrapped = make()(func)
    assert wrapped.__name__ == func.__name__
    assert wrapped.__doc__ == func.__doc__
    assert wrapped.__wrapped__ is func


@pytest.mark.parametrize("func", ALL)
def test_signature_is_the_same(func: Callable[..., Any]) -> None:
    assert inspect.signature(make()(func)) == inspect.signature(func)


def test_async_def_stays_coroutine_function() -> None:
    wrapped = make()(coro)
    assert inspect.iscoroutinefunction(wrapped)
    obj = wrapped(1)
    assert inspect.iscoroutine(obj)
    assert asyncio.run(_await(obj)) == 3


@pytest.mark.parametrize("func", FAILING)
def test_exception_comes_out_unchanged(func: Callable[..., Any]) -> None:
    with pytest.raises(ValueError) as info:
        run(make()(func))
    assert info.value is BOOM


@pytest.mark.parametrize("func", [gen, agen])
def test_generator_yields_the_same_items(func: Callable[..., Any]) -> None:
    assert run(make()(func), 4) == [0, 1, 2, 3]
    assert inspect.isasyncgenfunction(make()(func)) == inspect.isasyncgenfunction(func)


def test_early_close_runs_inner_cleanup() -> None:
    closed: list[str] = []

    def g() -> Generator[int, None, None]:
        try:
            yield from range(10)
        finally:
            closed.append("gen")

    async def ag() -> AsyncGenerator[int, None]:
        try:
            for i in range(10):
                yield i
        finally:
            closed.append("agen")

    it = make()(g)()
    assert next(it) == 0
    it.close()

    async def early() -> None:
        ait = make()(ag)()
        assert await anext(ait) == 0
        await ait.aclose()

    asyncio.run(early())
    assert closed == ["gen", "agen"]
```

Против обёртки без `functools.wraps` (положите рядом `broken.py` из следующего блока; `DECORATOR_MODULE` называет модуль, в котором лежит `measured`), красный:

```python
from collections.abc import Callable
from typing import Any


def measured() -> Callable[[Callable[..., Any]], Callable[..., Any]]:
    def decorate(func: Callable[..., Any]) -> Callable[..., Any]:
        def wrapper(*args: Any, **kwargs: Any) -> Any:  # нет functools.wraps
            return func(*args, **kwargs)

        return wrapper

    return decorate
```

## Как проверить любой декоратор

1. Имя, документация и `__wrapped__` у декорированной функции совпадают с исходными?
2. `inspect.signature` у обёртки такая же, как у исходной функции?
3. Тип функции сохранён: `async def` остаётся корутинной функцией, генератор остаётся генератором?
4. Исключение выходит наружу того же типа и тем же объектом, а не `None` и не подменено?
5. Состояние (счётчик, кэш) относится к одной функции и учитывает аргументы?
6. Тело декоратора ничего не делает при импорте, а время меряется через `perf_counter`, и повторяется только то, что можно повторять?

## Что спросят дальше

- **Зачем `functools.wraps`?** Копирует `__name__`, `__doc__`, `__qualname__`, аннотации и кладёт оригинал в `__wrapped__`, по которому `inspect.signature` восстанавливает настоящую сигнатуру. Без него логи, фикстуры и контейнеры зависимостей видят `wrapper`.
- **Как задекорировать и sync, и async одним декоратором?** Определить тип через `inspect.iscoroutinefunction` (а для генераторов `inspect.isgeneratorfunction`, `inspect.isasyncgenfunction`) и вернуть обёртку своего вида. Обычная обёртка на `async def` вернёт корутину без выполнения.
- **Почему обёртка на генераторе меряет ноль?** Вызов генератора не выполняет тело, а только создаёт объект. Нужна обёртка-генератор с `yield from` (для async-генератора ручной цикл с `asend`, `athrow`, `aclose`).
- **Как поддержать `@deco` и `@deco()`?** Принимать функцию необязательным позиционным первым аргументом, параметры только именованные.
- **В каком порядке ставить `@property` и свой декоратор?** Встроенный дескриптор сверху, свой под ним.
- **Почему нельзя вешать `retry` на что угодно?** Таймаут не значит «не выполнилось»; повтор неидемпотентной операции делает её дважды. Нужен ключ идемпотентности или отказ от повтора.
