Готовый декоратор `measured`, который меряет время и память любой функции: обычной, `async def`, генератора и async-генератора. На каждый вызов он пишет в лог одну строку: имя, исход, стену и CPU в мс, при `memory=True` ещё пик памяти. Рядом контекстный менеджер `measure_block` для куска кода. Код можно копировать в проект; как устроены декораторы, написано в заметке [[Декораторы]], а типичные поломки обёрток разобраны в [[Починка декораторов]].

## Что решено и почему

Использование: `@measured()` и `@measured(memory=True)`. Результат функции возвращается как был, исключения проходят наружу без изменений. Решения, которые стоит знать до копирования:

- **Тип функции** определяется один раз при декорировании через `inspect.iscoroutinefunction`, `inspect.isgeneratorfunction` и `inspect.isasyncgenfunction`. Проверки не пересекаются: async-генератор не считается корутинной функцией, и наоборот. Зачем нужна развилка: разделы про async и генераторы страницы [[Починка декораторов]].
- **Генераторы** меряются целиком, от первого `next()` до конца итерации. Ранний выход потребителя (`close()` у генератора, `aclose()` у async-генератора) тоже пишет строку, с исходом `closed`. Генератор, у которого не вызвали ни одного `next()`, ничего не пишет: его тело не стартовало. Стена включает паузы потребителя между элементами, а не только работу внутри генератора. Для sync-генератора обёртка делегирует через `yield from`, для async-генератора нужен ручной цикл с `asend`, `athrow` и `aclose`.
- **Отмена.** В `async def` отмена задачи (`CancelledError`) попадает в `except BaseException`, исход записывается как `CancelledError`, исключение уходит дальше. Отмену не глотаем.
- **CPU** считает `time.process_time()`: время процессора всего процесса, всех потоков и всех задач. Для функции, которая работает рядом с другими задачами, оно включает и чужую работу. Стена меряется через `time.perf_counter()`, причины в разделе «Часы, которые идут назад» страницы [[Починка декораторов]].
- **Типизация** через `ParamSpec`: сигнатура декорированной функции видна типизатору как у исходной. Внутри ветки возвращают `cast`: типизатор не может связать `R` с обёрткой другого вида, а снаружи сигнатура остаётся честной. Раздел «Типизация декоратора» заметки [[Декораторы]].
- **Логгер** берётся из аргумента или по имени модуля функции, формат и уровень задаёт приложение. Про настройку: [[Логирование]].
- **`@measured` без скобок** падает сразу с `TypeError`: параметры только именованные.

## Код и прогон

Файл сохраняется как `measured.py`: тест со страницы [[Починка декораторов]] импортирует его. Запуск `python3 measured.py` печатает демонстрацию, `import measured` ничего не печатает.

```python
import asyncio
import functools
import inspect
import logging
import time
import tracemalloc
from collections.abc import AsyncGenerator, Callable, Generator, Iterator
from contextlib import contextmanager
from typing import Any, ParamSpec, TypeVar, cast

P = ParamSpec("P")
R = TypeVar("R")

BYTES_IN_KIB = 1024
MS = 1000.0


class _Probe:
    """Один замер: стена, CPU, при желании пик памяти. Пишет ровно одну строку."""

    def __init__(self, label: str, memory: bool, log: logging.Logger) -> None:
        self.label = label
        self.memory = memory
        self.log = log

    def start(self) -> None:
        self.owns_tracing = False
        if self.memory:
            if not tracemalloc.is_tracing():
                tracemalloc.start()
                self.owns_tracing = True
            tracemalloc.reset_peak()
            self.base_bytes = tracemalloc.get_traced_memory()[0]
        self.wall0 = time.perf_counter()
        self.cpu0 = time.process_time()

    def finish(self, outcome: str) -> None:
        wall_ms = (time.perf_counter() - self.wall0) * MS
        cpu_ms = (time.process_time() - self.cpu0) * MS
        extra = ""
        if self.memory:
            if tracemalloc.is_tracing():
                peak_kib = (tracemalloc.get_traced_memory()[1] - self.base_bytes) / BYTES_IN_KIB
                extra = f" peak_kib={peak_kib:.0f}"
            else:  # параллельный замер уже остановил tracemalloc
                extra = " peak_kib=n/a"
            if self.owns_tracing:
                tracemalloc.stop()
        self.log.info("%s outcome=%s wall_ms=%.1f cpu_ms=%.1f%s", self.label, outcome, wall_ms, cpu_ms, extra)


def _outcome(exc: BaseException) -> str:
    # GeneratorExit — не ошибка, а ранний выход потребителя (close/aclose)
    return "closed" if isinstance(exc, GeneratorExit) else type(exc).__name__


def measured(
    *, memory: bool = False, logger: logging.Logger | None = None
) -> Callable[[Callable[P, R]], Callable[P, R]]:
    """Замер вызова: def, async def, генератор и async-генератор. Исключения идут дальше как были."""

    def decorate(func: Callable[P, R]) -> Callable[P, R]:
        label = func.__qualname__
        log = logger or logging.getLogger(func.__module__)

        def probe() -> _Probe:
            return _Probe(label, memory, log)

        if inspect.isasyncgenfunction(func):

            @functools.wraps(func)
            async def agen_wrapper(*args: Any, **kwargs: Any) -> AsyncGenerator[Any, Any]:
                p, outcome = probe(), "ok"
                p.start()
                inner = func(*args, **kwargs)
                try:
                    try:
                        value = await anext(inner)
                        while True:
                            try:
                                sent = yield value
                            except GeneratorExit:  # aclose(): закрыть и внутренний
                                await inner.aclose()
                                raise
                            except BaseException as exc:  # athrow(): передать внутрь
                                value = await inner.athrow(exc)
                            else:
                                value = await inner.asend(sent)
                    except StopAsyncIteration:
                        pass
                except BaseException as exc:
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], agen_wrapper)

        if inspect.isgeneratorfunction(func):

            @functools.wraps(func)
            def gen_wrapper(*args: Any, **kwargs: Any) -> Generator[Any, Any, Any]:
                p, outcome = probe(), "ok"
                p.start()  # тело генератора стартует с первого next()
                try:
                    return (yield from func(*args, **kwargs))
                except BaseException as exc:
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], gen_wrapper)

        if inspect.iscoroutinefunction(func):

            @functools.wraps(func)
            async def async_wrapper(*args: Any, **kwargs: Any) -> Any:
                p, outcome = probe(), "ok"
                p.start()
                try:
                    return await func(*args, **kwargs)
                except BaseException as exc:  # включая CancelledError
                    outcome = _outcome(exc)
                    raise
                finally:
                    p.finish(outcome)

            return cast(Callable[P, R], async_wrapper)

        @functools.wraps(func)
        def sync_wrapper(*args: Any, **kwargs: Any) -> Any:
            p, outcome = probe(), "ok"
            p.start()
            try:
                return func(*args, **kwargs)
            except BaseException as exc:
                outcome = _outcome(exc)
                raise
            finally:
                p.finish(outcome)

        return cast(Callable[P, R], sync_wrapper)

    return decorate


@contextmanager
def measure_block(name: str) -> Iterator[None]:
    """То же для блока кода: with measure_block("разбор файла"): ..."""
    p, outcome = _Probe(name, False, logging.getLogger(__name__)), "ok"
    p.start()
    try:
        yield
    except BaseException as exc:
        outcome = _outcome(exc)
        raise
    finally:
        p.finish(outcome)


if __name__ == "__main__":
    import sys

    logging.basicConfig(level=logging.INFO, format="%(message)s", stream=sys.stdout)

    @measured()
    def crunch(n: int) -> int:
        return sum(i * i for i in range(n))

    @measured(memory=True)
    def build_list(n: int) -> int:
        return len([0] * n)

    @measured()
    async def fetch(delay: float) -> str:
        await asyncio.sleep(delay)
        return "данные"

    @measured()
    def numbers(count: int) -> Generator[int, None, None]:
        for i in range(count):
            time.sleep(0.02)
            yield i

    @measured()
    async def ticks(count: int) -> AsyncGenerator[int, None]:
        for i in range(count):
            await asyncio.sleep(0.02)
            yield i

    @measured()
    def broken() -> None:
        raise ValueError("упала")

    async def main() -> None:
        print("sync:", crunch(300_000))
        print("sync + память:", build_list(1_000_000))
        print("async:", await fetch(0.1))
        print("генератор:", list(numbers(3)))
        print("async-генератор:", [x async for x in ticks(3)])
        try:
            broken()
        except ValueError as exc:
            print("вызывающий получил:", repr(exc))
        gen = numbers(10)
        print("ранний выход, первый элемент:", next(gen))
        gen.close()
        agen = ticks(10)
        print("ранний выход, первый элемент:", await anext(agen))
        await agen.aclose()
        with measure_block("блок"):
            time.sleep(0.05)

    asyncio.run(main())
```

Числа wall, cpu и peak от запуска к запуску меняются: время плавает, 7813 КиБ около восьми мегабайт под миллион указателей. Порядок строк как на терминале: строка лога выходит раньше `print` с результатом, потому что `print` получает значение после возврата из функции. В строках `closed` видно, что замер генератора записался и при раннем выходе. На 3.12 вывод по строкам такой же, различаются только числа.

## Замер куска кода

`measure_block(name)` даёт тот же замер для блока внутри функции: `with measure_block("блок"): ...`, в демонстрации это последняя строка лога. Это обычный контекстный менеджер на `@contextmanager`: исключение из блока проходит наружу, а в логе исход равен имени исключения. Устройство менеджеров: [[Контекстные менеджеры]].

## Память

`memory=True` включает `tracemalloc` на время вызова. Он хранит трейс каждого выделения и замедляет программу, поэтому включать его нужно на время диагностики, а не навсегда. Пик общий на процесс: параллельные замеры с `memory=True` портят числа друг другу, а если первый из них остановил `tracemalloc`, второй пишет `peak_kib=n/a` вместо отрицательного числа. `measured` останавливает `tracemalloc` только если сам его включил. Пик считается от значения на входе в функцию, а не от нуля.

## Что спросят дальше

- **Почему нельзя мерить генератор обычной обёрткой?** Вызов генератора не выполняет тело, замер получится около нуля. Нужна обёртка-генератор.
- **Почему `perf_counter`, а не `time.time`?** Первый монотонный, второй могут перевести назад.
- **Что показывает CPU у async-функции?** Время процессора всего процесса за время вызова, включая работу соседних задач.
- **Как проверить, что мой декоратор не ломает функцию?** Тест из страницы [[Починка декораторов]].
