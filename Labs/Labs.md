Лабы — стенды, на которых утверждения из статей можно проверить руками, а не принимать на веру. Каждая лаба — это код стенда в этом репозитории и страница с опытами: команда, вывод, снятый на стенде, и ссылка на раздел статьи, который опыт подтверждает. Статьи в ответ ссылаются на свою лабу.

## Как запустить

Нужны git и Docker (Docker Desktop или Docker Engine с Compose v2).

```sh
git clone https://github.com/iamthen0ise/reference.git
cd reference
make pglab-up      # у каждой лабы свои команды — на её странице
```

Код лаб лежит в [`Labs/`](https://github.com/iamthen0ise/reference/tree/main/Labs) по каталогу на стенд; подробности — в `README.md` стенда. Стенды рассчитаны только на локальный запуск: пароли простые, порты слушают 127.0.0.1.

## Лабы и песочницы

Кроме лаб, у части статей есть песочницы: в них прогоняются блоки кода прямо со страницы, и вывод в статье снят там же. Это `make sql-up` для [[SQL-рецепты|SQL-рецептов]], `make linux-up` для статей раздела [[Linux]] и `make k8s-up` для [[Docker и Kubernetes]]. Песочница отвечает на вопрос «что выведет этот код», лаба — «как поведёт себя система из нескольких сервисов, если её нагрузить или сломать».

## Новая лаба

- Код стенда — в `Labs/<имя-стенда>/`: подкаталоги `Labs/` в vault и на сайт не попадают, поэтому `README.md` и прочие файлы стенда заметками не станут.
- Страница — `Labs/<Название>.md`, плюс строка в таблице выше и пункт `Labs` в `sidebar` в `.site/astro.config.mjs`.
- Команды запуска — цели `make <лаба>-up` и `make <лаба>-down`.
- Каждый опыт ссылается на раздел статьи, а статья — на лабу.
